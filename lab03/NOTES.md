git diff сравнивает две версии и показывает, что изменилось между ними.

git show показывает один конкретный коммит

git log показывает список истории

git log -S ищет коммиты, в которых появилась или пропала указанная строка (я искал "def").

git blame показывает для каждой строки файла, в каком коммите и кем она написана.
